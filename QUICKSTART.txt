CRIMSON PC CHECK V4 - WINDOWS

1. Install Node.js 22+ from https://nodejs.org if it is not installed.
2. Extract the ZIP. Double-click start-crimson.cmd. Keep this window open.
3. Open http://localhost:3000. Set up your staff password or sign in.
4. Import trusted signature JSON, or use Add a signature with its evidence
   reference. Click Save library. It persists across server restarts.
   No library means inventory only, never a "clean PC" verdict.
5. Create a session. The invitation dialog shows its PIN, expiry and status.
   For local testing, click Guided scanner on the session row.
   For a player on another PC, first configure HTTPS hosting (HOSTING.md),
   then copy the private player link or QR from the invitation dialog.
6. Open the downloaded EXE. A Crimson window opens (Edge/Chrome app mode, browser fallback) with server and code
   already filled in. No PROCESSES / YES / SEND terminal commands required.
7. Choose a folder and/or opt in to running executable file hashing.
   Check the permission box, then click Commencer la verification.
8. Review the report. Check the sharing permission box and click Envoyer.
9. The staff site refreshes automatically. Open View report. Search, filter,
   export JSON or re-analyze against your saved library. Original evidence
   is retained; harmless test and allowed signatures are labeled separately.

FALLBACK: the generic EXE is in dist/crimson-pc-check-windows-amd64.exe.
It opens the same wizard; enter your session PIN there (new eight-character or legacy six-digit).

The native build is unsigned. Follow your Windows security policy. Do not
 disable antivirus or bypass platform warnings. The base EXE has a checksum
in dist/checksums.txt. Session EXEs include a private configuration footer
and therefore have different hashes. The website checks the base checksum
before appending the session code; this does not replace publisher signing.

For local testing, use the same PC for the staff site and scanner. localhost
means this PC. Across different PCs, deploy the staff server behind HTTPS
and use its real domain. No public hosting is included.

No verified FiveM cheat feed is bundled. Staff-provided signatures require
independent review. A match is not proof of cheating. This is not a full-PC
or process-memory anti-cheat, and client reports are not attested.

See UPDATE.txt to preserve your existing data when updating from Sentinel.

OPTIONAL V3 SOURCES
The scanner offers FiveM loaded DLL hashes, cached Windows signature trust,
boot/system facts and existing execution event metadata. Every option is
explicit. Unavailable logs/access are displayed as limited coverage.
No external cheater databases are connected. No tool detects every cheat.

V4 OPTIONS
The standard-location option is selected initially: review its listed
Desktop/Downloads/Documents/Temp/FiveM locations, then authorize the scan.
It finds EXE/DLL files within limits; it still needs saved signatures for
exact matches. You can add a specific folder or disable standard discovery.
Enable full paths if you want staff to see where a detected file is located.
Enable profiles only if you want to share locally remembered Steam public
profile IDs; a Discord ID is optional and entered by the player, not extracted.
No automatic Discord account verification or all-account inventory is claimed.
Copy local link now works, but only on this same PC. Internet invitations
still need a deployed HTTPS server.
