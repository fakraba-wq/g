SENTINEL - FIRST LOCAL TEST (WINDOWS)

1. Install Node.js 22 or later from https://nodejs.org.
2. Extract the whole project ZIP. Do not run files from inside the ZIP.
3. Double-click start-sentinel.cmd and keep the terminal open.
4. Open http://localhost:3000 in your browser.
5. Create a staff password (at least 12 characters).
6. Import a trusted signature JSON list before creating a session.
   Without signatures, results are UNVERIFIED, not clean.
7. Create a session and note its six-digit code.
8. Download the Windows scanner using the website button.
   It is unsigned. Review the included client source and follow your
   Windows security policy. Do not disable antivirus or security warnings.
9. On the SAME Windows PC for this local test, run the scanner.
   Enter http://localhost:3000, your code and a folder you own.
   Optional running executable hashing requires separate opt-in.
10. Review the local JSON report before choosing SEND.
11. Refresh sessions in the website, view the report and export it.

localhost means this PC only. For checks across different PCs, first deploy
the server behind HTTPS and use its real HTTPS domain in the scanner.
There is no public deployment included.

This is an MVP, not a proven commercial anti-cheat. The Windows binary has
been cross-compiled; Windows process inspection needs real Windows testing.
No verified cheat database is included. An exact match is evidence for review,
not proof that the player cheated. No match does not prove a clean PC.

See README.md for hosting, security, build and testing details.
